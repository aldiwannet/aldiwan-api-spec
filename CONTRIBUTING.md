# Contributing

Thank you for improving AlDiwan's developer experience.

1. Open an issue for contract changes before implementing them.
2. Keep the specification limited to the documented public API.
3. Do not add real keys, private endpoints, user data, or production payloads.
4. Update both OpenAPI and Postman when an endpoint changes.
5. Add an entry under `Unreleased` in `CHANGELOG.md`.
6. Run `npm test` and submit a focused pull request.

Breaking changes require an explicit versioning and migration plan. Examples must use placeholders and must preserve the required content attribution.
