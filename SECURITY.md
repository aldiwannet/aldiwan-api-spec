# Security policy

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities, leaked credentials, or abuse paths. Use GitHub's private vulnerability reporting for this repository. Include the affected endpoint or specification section, impact, reproduction steps, and suggested mitigation when available.

Do not include real API keys, personal data, or production response bodies. We will acknowledge a complete report as soon as practical and coordinate remediation and disclosure privately.

Only the latest released specification version is supported. Never commit an API key; rotate it immediately through the developer platform if it is exposed.
